# Download checksums (SHA-256)

Each app publishes its own downloads and fingerprints. Current versions: Ludus 1.12.67, Memo 1.4, Nox 1.5.3, Awayke 1.8.0, Weather 1.1.1, Stats 1.0.1. Open the app's release page to see the fingerprints (also listed in each app's CHECKSUMS.md):

- Ludus 1.12.67: https://github.com/Solomon-69/Ludus/releases/tag/v1.12.67
- Memo 1.4: https://github.com/Solomon-69/Memo/releases/tag/v1.4
- Nox 1.5.3: https://github.com/Solomon-69/Nox/releases/tag/v1.5.3
- Awayke 1.8.0: https://github.com/Solomon-69/Awayke/releases/tag/v1.8.0
- Weather 1.1.1: https://github.com/Solomon-69/Weather/releases/tag/v1.1.1
- Stats 1.0.1: https://github.com/Solomon-69/Stats/releases/tag/v1.0.1

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.
