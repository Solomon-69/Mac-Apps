# Download checksums (SHA-256)

Each app publishes its own downloads and fingerprints. Current versions: Ludus 1.5, Memo 1.2, Nox 1.1, Awayke 1.5. Open the app's release page to see the fingerprints (also listed in each app's CHECKSUMS.md):

- Ludus 1.5: https://github.com/Solomon-69/Ludus/releases/tag/v1.5
- Memo 1.2: https://github.com/Solomon-69/Memo/releases/tag/v1.2
- Nox 1.1: https://github.com/Solomon-69/Nox/releases/tag/v1.1
- Awayke 1.5: https://github.com/Solomon-69/Awayke/releases/tag/v1.5

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.
