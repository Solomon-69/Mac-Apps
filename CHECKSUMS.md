# Download checksums (SHA-256)

Each app publishes its own downloads and fingerprints. Current versions: Ludus 1.12.49, Memo 1.3, Nox 1.4.3, Awayke 1.7.2. Open the app's release page to see the fingerprints (also listed in each app's CHECKSUMS.md):

- Ludus 1.12.49: https://github.com/Solomon-69/Ludus/releases/tag/v1.12.49
- Memo 1.3: https://github.com/Solomon-69/Memo/releases/tag/v1.3
- Nox 1.4.3: https://github.com/Solomon-69/Nox/releases/tag/v1.4.3
- Awayke 1.7.2: https://github.com/Solomon-69/Awayke/releases/tag/v1.7.2

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.
